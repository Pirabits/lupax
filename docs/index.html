Inspect and capture any web page

Screenshots, screen recordings, CSS styles, design tokens, assets and accessibility checks in one Chrome extension, for designers and developers.

Chrome Web Store: coming soon View on GitHub

Chrome 116 or later. Nothing you capture leaves your browser.

Everything included

Every feature is free. There is no account, no Premium tier and no upload to anyone's cloud.

Capture

Visible area, a selected region, the full page, a single element or your desktop. Save as PNG, JPG or PDF, copy to the clipboard, or annotate first.

Annotate

Pen, highlighter, arrows, shapes, text, blur and crop, with undo and keyboard shortcuts.

Record

Record a tab, a window or the whole screen with microphone, system audio and a webcam bubble, at up to 4K and 60 fps.

Inspect CSS

Hover any element for its box model, styles and contrast, then copy its CSS. See the page's colors, typography, spacing and components.

Export design tokens

Export the page's colors, fonts and spacing as W3C design-token JSON, CSS variables or a Tailwind theme.

Assets

Browse a page's images, SVGs, fonts and icons, then download them one by one or as a ZIP.

Accessibility

Get a score and a report covering contrast, alt text, labels, headings and more, with "Show on page" for each issue.

Private by design

LupaX runs entirely in your browser.

No servers, no accountsCaptures and recordings stay on your device. Nothing is sent to us.
No trackingNo analytics, telemetry or ads, in the extension or on this site.
Minimal accessLupaX can read a page only after you click its icon or use a shortcut there.
