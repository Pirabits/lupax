Install LupaX in Chrome

Add LupaX from the Chrome Web Store and Chrome keeps it up to date. To run it from source instead, it takes about a minute.

  1. 1Clone the repository from GitHub.
  2. 2Open chrome://extensions and turn on Developer mode.
  3. 3Click Load unpacked and choose the lupax folder.

Is LupaX really free?

Yes. Every feature is free, with no account, trial or watermark, and the code is open source under Apache-2.0.

Does LupaX send my captures anywhere?

No. Captures, recordings and exports stay in your browser and your Downloads folder. LupaX only contacts the sites whose assets you export.

Why does LupaX ask for these permissions?

To work in the tab you click it on, record, save files and copy to the clipboard. It asks for other sites only during a ZIP export, and gives that access back after. The privacy policy lists each one.

Does LupaX work in other browsers?

It is built and tested for Chrome 116 or later. Other Chromium browsers may work, but they are not tested.

How do I report a bug or a security problem?

Open an issue on GitHub. Report security problems privately, as the security policy describes.
